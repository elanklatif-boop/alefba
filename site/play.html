Two games for a Persian class

Put Alefba on the classroom screen and pick a game, then the words to play with.

  • 🎈 BalloonsAlefba says a Persian word, and the class shouts which balloon to pop. Play it with pictures for beginners, or with the words written in Persian for readers.
  • 🎉 BingoPrint a card for every child, each one different, with pictures or with words in Persian. The screen calls a word out loud, then shows it a few seconds later so the class can check. The first full line wins.

Which words can we play with?

The words from each level of Alefba, like family, food, colours and animals, and the seasonal packs: the Yalda words in December, with watermelon, pomegranate and the fâl of Hafez. The first 3 levels and the seasonal packs are free to play. A plan opens all 16 levels.

How to run it

Open learnalefba.com/play on the screen the class can see, choose Balloons or Bingo, then choose Pictures (easier) or Read it (harder), and a level. For bingo, print the cards first. Each set of printed cards has a game code, so you can open the same game again next week.

Getting ready for Yalda? The Yalda page has a Yalda bingo, a balloon game and a short story, all set up for a class.

More for teachers

Teacher mode is free: make a class, share one link, assign lessons and see who's practising. There are also printable tracing sheets for every letter. See Alefba for Persian teachers.
